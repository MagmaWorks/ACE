# ACE - Advanced Column Engineering
Project to check the structural capacity of a (concrete) column design, by calculating a 3D interaction diagram of the cross-section. 

Using an enhanced technique to enable leaner and less-conservative solutions. 

The app also includes a 3D graphics view to enable a clear and intuitive understanding of the designs, so optimisation is easier and the design process is streamlined.

The table data provided by Eurocodes are often too conservative. The Fire design in this app therefore integrates advanced methods compliant with Eurocode EN 1992-1-2, based on the temperature profiles of the section under fire.
